# 剧情树参考与独立实现

用户指定参考《情感反诈模拟器》。本次查看的是公开截图与社区攻略，并非亲自运行该游戏。

- [Steam 社区全故事线指南](https://steamcommunity.com/sharedfiles/filedetails/?id=3503935242)：说明早期选择、关系条件与后续选项的关联，以及修改早期节点再推进/读档的收集方式。
- 同指南的公开故事线截图：章节导航、缩略图节点、实线/虚线分支、探索度、缩放与当前节点定位。

《残响协议》独立实现了章节剧情DAG、缩略图、已探索/未知节点、当前路径、缩放与拖动、节点状态选择和直接改选。未探索内容隐藏标题与图像。

每个已到达节点保存最多三份不同前置路线的快照。回溯明确恢复这份快照里的证据、关系、个人记忆标记与已作出的选择，后续进度重新生成。全局探索和已收集结局独立保留，避免将新选择套入旧终章的状态。运行所用图形布局、存档代码、剧情和资源均为本项目实现，没有复制参考游戏的程序或画面。
