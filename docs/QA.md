# 发布前验证 · V3.0

2026-10-14完成。

- 静态剧情/资源校验：五章、60场景、595段台词、三个结局全部具有合法出口；图像引用全部存在。
- Node测试六项通过，穷举1,536条选择组合；所有节点、选项、结局均可达，无循环或死路。
- 验证关系数值、条件台词、回响、章节输入状态及存档回读。
- 验证无效/恶意存档在替换之前被拒绝，旧存档键不被覆盖，浏览器存储失败时仍能游玩和导出。
- Chromium实际运行：三种结局、手动保存、页面刷新后继续、真实选择按钮、紧急倒计时及暂停行为。
- 桌面1440×900、手机390×844画面检查；修复手机溢出，检查实际显示的背景与立绘解码。
- 12张立绘全部检查透明通道；背景与立绘图集人工视觉检查后才接入。
- JavaScript语法与Git空白检查通过。

本地检查命令：`npm run check`、`npm test`。浏览器验证脚本为 `tools/browser_qa.py`，使用Python Playwright和系统Chromium；其运行环境依赖与游戏运行依赖无关。调试接口仅在URL附加 `?debug=1` 时启用。

当前浏览器验证基于Chromium，尚未逐台实机测试Safari及各手机厂商浏览器。所有音频从首次用户交互后启动，不支持全屏的设备会保留普通浏览器模式。游戏为静态部署，进度在浏览器本地保存，无服务端同步。
