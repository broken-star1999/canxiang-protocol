# 美术规范与使用记录

用户指定经典Galgame：清晰线稿、赛璐璐上色、鲜明表情、二维动漫绘景。最初偏厚涂/写实的一批已放弃，不进入游戏或仓库。

角色图集与背景采用同一套明确的二维参考。MIRA为白色短发、青色发夹、深蓝研究制服；周衡为黑发、灰色工作服与腕部绷带；唐棠为栗色发、黄色开衫、植物发夹；林述为蓝黑发、白色研究外套与工作手套。每人三张表情，姿态变化为剧情服务。立绘使用真实透明通道，未通过背景抠除伪造透明。

背景八处：实验舱、茶水间、海侧连廊、林述办公位、临海平台、唐棠家、档案室、控制室。实验舱开场由演出层降低明度；温暖茶水间、家庭通信、海边晨光提供节奏变化。

原图集在 `art/v3-source/`，游戏使用 `assets/` 内拆分后的WebP，整体运行美术约1.9MB。场景在浏览器中按实际台词、立绘站位与对话框检查。原图保留供后续重画与重新拆分。

生成方式：使用AI图像生成工具，以明确的Galgame线稿/平涂规范生成两张四格背景图集、四张三表情人物图集。后者以MIRA图集作为风格参考；第二背景图集以第一张为风格参考。图集拆分仅裁切与编码，不重新绘制角色或风格。下一轮可按剧本新增专用CG、医疗服装与手部特写；当前版本通过通信标记、表情与叙述完成这些段落。
