# 残响协议 · 美术规范

经典日漫Galgame风格：清晰线稿、赛璐璐上色、鲜明且克制的表情、二维动漫绘景。色彩以灰蓝、低饱和青与清晨琥珀色为主，生活场景加入黄色与薄荷绿。

## 角色与服装

- MIRA：白色短发、青色发夹、深蓝研究制服与青色饰线。她在剧情中通过终端呈现；事件CG明确保留显示屏与移动终端。
- 周衡：外观24–27岁的黑发青年，无胡茬。灰蓝短款站务工装、深灰肩片、浅色圆领内搭、站务标识；右腕原有绷带保持一致。救援后轻伤增加左袖破损和左前臂包扎，只在相应分支出现。
- 唐棠：栗色发、植物发夹、黄色开衫、浅色日常内搭与蓝色牛仔裤。问候、身份揭穿与接纳有不同表情和手势；视频通话与现场相见使用不同通信标记。
- 林述：工作录音使用白色研究外套、深色内搭与工作手套；医疗通信使用浅灰蓝病服，受伤左臂固定在吊带里，只有健康右手作出手势。

运行中共23张不同立绘：MIRA六张、周衡六张、林述六张、唐棠五张。重复表情别名不计为独立立绘。立绘全部具有透明通道，统一560×1024画布；人物在手机上的单人和双人站位分别处理。

## 场景与事件

十六张背景包含实验舱、茶水间、海侧连廊、办公位、临海平台、家庭、档案室、控制室、医疗舱、维护区、码头，以及夜色、晨光、警戒和次日等变体。镜头切换遵循台词中的实际位置；远程取证阶段留在档案室，到达机械门后再切到维护区。

四张事件CG：接缝之下、门的另一边、初次问候、自己的署名。CG只出现在相应剧情分支，不提前展示身份或成功救援。画面完整显示在对话框上方，可隐藏对话赏图，读到之后收入画面档案。
