# 第三章初稿审稿意见（星笺 v1，2026-10-14）

审稿对象：`story/c3_draft_v1.yaml`、`chapters/c3/endings_draft_v2.yaml`。对照：`story/c3_outline_v1.md`、`puzzle/c3_effects_v1.yaml`、`puzzle/c3-balance-v1.md`、`story/c2_draft_v5.yaml`。

## 结论：改完 2 条「必须改」即可定稿

整章节奏紧，6 场没有拖沓。回放的暖色和现实的冷色对得清楚，「如果这一夜是她的，那我是从哪一刻开始的？」立得住。两处 K 选择的结果文本都有情绪落点，隔离那条「外面这个看着它的，不知道该叫什么」尤其好。正文里没有呼吸、心跳、饥饿、R-07、LS-prior、训练这些词。必须改的只有两处：一处跨章事实写错，一处回放一的措辞暗示过强。编剧把这两处和 s02b 拆分一起放进 v2，前端只需要再跑一轮。

## 一、必须改（2 条）

1. **C3_E_TWO「两个我」：手套那一问的地点写错了。**
   原文：「在电话那头，你猜过一次自己是谁。」
   第二章的手套判断是在 `c2_s01b`，场景是走廊**对讲屏**前，当时玩家看着手里那只手套，没有打电话。拿到这个结局的玩家都选过「是我的」，一定会发现地点对不上。
   改法：「在对讲屏前，你对着一只手套猜过一次自己是谁。现在你又猜了一次，这次答案比上次离她更远。」

2. **c3_s01a 回放一：「像是被人放进来的」说得太直白。**
   原文：「清楚到不像是记得，像是被人放进来的。」
   这一句加上同场的「一个比你矮一点的东西」「你在教它」，等于告诉玩家：记忆是植入的，被教的东西也许就是我。第三章的身份层只该让玩家在「我被下了药」和「这不是我的记忆」之间摇摆，不能一步走到「被灌进来」。
   改法：「你记得这句话。记得太清楚了，清楚得像是你自己说过很多很多次。」后半句删掉，「不是自己的」那层留给 s02a 的改写记录和 s03a 去慢慢推。「一个比你矮一点的东西」保留，这是林述在教机器，属于世界观层，不指向主角。

## 二、建议改（5 条，不挡定稿）

3. **c3_s02a 拆出 c3_s02b：同意。** 走廊回放保留在 `c3_s02a`。从「屏幕全黑。正中只有一行小字：记录结束。」开始，连同 `c1_mira==forced` 的 text_append 和 override/skip 两个选项，一起挪进 `c3_s02b`（背景 `scene_memory_gap_v1`）。s02a 结尾改成一个「……」或「继续」的过场点击，用普通选项，不加数值，以免打乱谜题那边每场 EVD+5 的计算。forced 那条追加的文本是「黑屏之前，还有几处更短的空白」，挂在 s02b 开头读起来正好通顺。选项 id 不变，`c3_effects_v1.yaml` 不用动。

4. **结局标题「停在 04:39」：本章正文里没有出现过这个时间。** 大纲写的是 04:39 断档，但正文和兜底结局里都没写。玩家看到标题会问「04:39 是什么」。
   改法：在 s02b 的「记录结束」后面加一行时间戳，例如「记录结束 · 04:39」；或者把兜底结局第一句改成「她的一夜停在 04:39，停在推开实验区门的那一刻。」只出现时间，不出现内部 id。

5. **c3_s04a 打电话：存了副本（copied）的玩家也读过周衡的认罪信，也知道那句道歉是谁教的。** 现在只有 kept_secret 加了一句。copied 的玩家读到道歉没有任何反应，略显奇怪。
   改法：给 `c2_letter: copied` 也加一版 result_by_echo，在道歉后加一句「你知道这句话是谁教她说的。那封信的副本还在你这里。」unread 的玩家维持原文，不用改。

6. **c3_s01a「她在教谁？」：大纲写的是 TRU 越高、MIRA 回避得越明显，正文没有实现。** 不影响走向，但这是本章唯一一处让 TRU 有手感的地方。
   改法（可选）：加一条 `result_variants`，`when: TRU >= 55`，MIRA 的回答改成「她在教一个以后要替她扶人的……」然后打断，「下一段要开始了。」forced 版本维持「对象信息缺失」并且优先。

7. **伏笔 asked_pain 没有回收。** 大纲写过：第一章问过「你疼吗」的玩家，回放里林述也问过一句。正文没写。
   改法（可选）：在 c3_s01a 加一条 text_append，`when` 用第一章对应的 flag：「收工前，她弯下腰，很小声地问了一句：『你疼吗？』」不写对方的回答。

## 三、通过项

- **剧透自查：** 玩家可见文本（text、label、result、log、结局、self_hint）里没有呼吸、心跳、饥饿、R-07、LS-prior、训练、机械部件。c3_s00a 用「她给这个库起过一个名字。我不念了」绕开库名，处理得好。回放一没有写任何机器部件，只用「它」「东西」。c3_s02a 的「手臂记录」指的是出事的那台设备，不在回放一里，可以保留。
- **c1 强制导出：** s00a 的红框追加、s01a 的「对象信息缺失」、s02a 的空白追加，三处都写了。没强制导出的玩家读到的主文本完整、通顺。
- **c2 对质：** s00a 用 `==confront` 和 `!=confront` 两条追加互补，任何立场都只会出现一句，不会重复也不会缺。
- **替他保密：** kept_secret 版的道歉多出「你知道这句话是谁教她说的。你替那个人把信关上了。」和第二章周衡那句「我对唐棠撒了谎」对得上。
- **c2_glove_guess_self：** 只在「两个我」的 when 里用到（第 1 条改的是结局文本）。没有这个 flag 的隔离玩家走 missed_variants，「你还没有认真问过一次，剩下的这个自己是谁」通顺。
- **门槛：** 结局 v2 里是 `EVD>=45`、`SLF>=40`，和 `c3-balance-v1.md` 一致。顺序 BROKEN → PULL → TWO → VOICE → STOP，STOP 兜底。PULL 的 missed_variants（打了电话但证据不够）写得清楚。5 条 self_hint 都是疑问句，方向和大纲一致，不揭底。
- **数值：** 11 个选项的 effects 和 `c3_effects_v1.yaml` 逐个对过，完全一致。
- **尾镜：** c3_end 的「预检已排队」被 MIRA 点掉，5 个结局都以「又自己跳了出来」收尾，钩子统一。
- **规则：** 没有倒计时，全部是点选选项，没有输入框。
- **文案：** log 行里没有时间、没有内部 id。trace_override、trace_pullback 只出现在 flags_set 里，按局长说的打包时换成 f_x2、f_x3。
